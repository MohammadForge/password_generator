# 🔒 password generator
A simple and customizable password generator built with python .The program creates secure random password based on user preferences , including password length and characters types.
# ⭐ Features
. Generate passwords of any chosen length 
. Include or exclude numbers, letters, symbols
. Customize password requirements
. Random password generating using pythons built-in libraries
. Simple command line interface
# Technologies 
. Python
. string module
. random module
